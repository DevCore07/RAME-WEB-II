# 🍽️ Rede Alimentar de Monitoramento Estudantil (RAME)

## 📌 Sobre o Projeto

A **Rede Alimentar de Monitoramento Estudantil (RAME)** é uma aplicação web desenvolvida com o objetivo de otimizar a gestão da alimentação no Instituto Federal do Ceará (IFCE) – Campus Maranguape.

O projeto busca promover **segurança alimentar, organização e eficiência**, criando uma ponte entre os estudantes e o setor de nutrição por meio da tecnologia.

A plataforma foi idealizada para atender uma necessidade real do ambiente acadêmico: o gerenciamento de **restrições alimentares**, como alergias, intolerâncias e outras condições nutricionais que impactam diretamente a saúde e o desempenho dos alunos.

---

## 🎯 Objetivos

- Garantir maior **segurança alimentar** aos estudantes  
- Facilitar o **gerenciamento de restrições alimentares**  
- Melhorar a **comunicação entre alunos e nutricionista**  
- Automatizar a **análise de cardápios**  
- Reduzir riscos à saúde no ambiente escolar  

---

## ⚙️ Funcionalidades

### 👨‍🎓 Alunos
- Login com dados institucionais  
- Cadastro e atualização de restrições alimentares  
- Visualização do cardápio semanal  
- Identificação de alimentos não recomendados  

### 👩‍⚕️ Nutricionista (Administrador)
- Acesso a painel administrativo  
- Gerenciamento de dados dos alunos  
- Cadastro de cardápios semanais  
- Sistema de alerta para conflitos alimentares  

---

## 🔄 Funcionamento do Sistema

O sistema opera em três etapas principais:

1. **Cadastro e Autenticação**  
   Os alunos realizam login e registram suas restrições alimentares.

2. **Armazenamento e Gerenciamento**  
   As informações são armazenadas em banco de dados e ficam disponíveis para a nutricionista.

3. **Cadastro e Análise do Cardápio**  
   O cardápio é inserido no sistema, que realiza o cruzamento automático com as restrições cadastradas, gerando alertas preventivos.

---

## 💡 Diferenciais do Projeto

- Sistema com foco em **prevenção de riscos alimentares**  
- Uso de tecnologia para **análise automatizada de dados**  
- Aplicação prática dentro do contexto acadêmico  
- Contribuição direta para a **permanência estudantil**
