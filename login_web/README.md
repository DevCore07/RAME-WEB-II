# 🚀 Mini Projeto Django

Esse é um mini projeto feito com o objetivo de **aprender os fundamentos do Django**, um dos frameworks mais utilizados em Python para desenvolvimento web.

## 📚 Sobre o projeto

A ideia principal foi colocar em prática conceitos básicos como:

* Criação de rotas (URLs)
* Uso de views
* Renderização de templates HTML
* Envio e captura de dados entre páginas

Além disso, o projeto explora o uso de **requisições GET e POST**, permitindo pegar informações de um formulário e utilizar esses dados dentro da aplicação.

## ⚙️ O que foi praticado

* Estrutura de um projeto Django
* Organização de apps
* Criação de templates
* Uso do `request.GET` e `request.POST`
* Integração entre páginas

## 🧠 Objetivo

Esse projeto não tem foco em ser algo complexo, mas sim em:

> Aprender na prática como o Django funciona e como os dados circulam dentro de uma aplicação web.

## 🛠️ Tecnologias utilizadas

* Python
* Django
* HTML

## ▶️ Como rodar o projeto

1. Clone o repositório:

```
git clone <link-do-repositorio>
```

2. Entre na pasta:

```
cd nome-do-projeto
```

3. Ative o ambiente virtual (se tiver):

```
.venv\Scripts\activate
```

4. Rode o servidor:

```
python manage.py runserver
```

5. Acesse no navegador:

```
http://127.0.0.1:8000/
```
